# EasyAsFckCMS
**_Easy As F*ck CMS_** is an CMS which is for people who **do not have full admin panel access** (e.c. cPanel), and **only rely on FTP access**.
**_Easy As F*ck CMS_** is also made for people which do not have a lot of IT abilities/or are new to CMS'es.

Made from total zero, using it's own engine based on PHP.
